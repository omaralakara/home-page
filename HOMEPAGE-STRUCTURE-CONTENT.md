# Synergi Homepage Structure and Content Blueprint

This is the canonical content order for the redesigned homepage. It combines the requested 2026 homepage brief with the search-relevant content already present in the project. Use it as the content source for the HTML concept and the Elementor build.

## Non-negotiable heading rules

- Use one `H1` on the page.
- Use one `H2` for the subject of each major homepage section.
- Use `H3` for service, industry, reason, location, event, article, and social-card titles.
- Do not use a heading tag for an eyebrow, number, metric label, button, decorative phrase, or footer legal text.
- Keep all search-relevant text in native WordPress/Elementor widgets so it exists in the initial HTML. Canvas, animation, and JavaScript are decoration only.

## SEO preservation checklist

- Keep the existing homepage URL and canonical: `https://synergi.ae/`.
- Keep the approved title and meta description in the SEO plugin unless search data supports a deliberate change.
- Preserve one visible H1 and the regional BPO topic.
- Preserve or deliberately map every important internal link, especially Accounting, HR, Procurement, Technology & AI, Marketing, Shared Services, KSA/Riyadh, Podcast, Media, Global Locations, Insights, and Contact Us.
- Do not paste the prototype JSON-LD into an Elementor HTML widget. Let the site's SEO plugin output Organization, WebSite, Breadcrumb, and page schema once.
- Keep the staging version blocked from indexing; remove that block only after the live page is ready.
- Compress images, provide descriptive alt text for meaningful images, and mark decorative images empty/hidden.
- Maintain keyboard access, visible focus states, reduced-motion behavior, and semantic links/buttons.
- Crawl the staging page before launch and the live page immediately afterward. Check status codes, canonicals, headings, internal links, schema, sitemap inclusion, analytics, Search Console, and Core Web Vitals.
- If any existing URL must change, add a direct one-to-one 301 redirect. Do not redirect unrelated pages to the homepage.
